Política de privacidad

Última actualización: 21 de octubre de 2026

Esta política describe cómo funciona el script personal “Cuota Clara Search Console Monitor” (el “Monitor”), operado por el propietario del sitio Cuota Clara para revisar sus propias páginas y su propiedad de Google Search Console. No es un servicio público multiusuario.

Datos a los que accede

Cuando el propietario autoriza el Monitor, este solicita acceso de solo lectura a la propiedad de Google Search Console configurada en el código. Consulta el estado conocido de indexación de cuatro URLs, el registro del sitemap y métricas de búsqueda como clics, impresiones, CTR, posición, páginas y consultas. También realiza solicitudes HTTP a las páginas públicas y al XML del sitemap para comprobar disponibilidad y leer el número de URLs.

El Monitor utiliza el correo de la cuenta o la dirección especificada por el propietario en la configuración para enviarle los informes. No está diseñado para obtener datos de otros usuarios ni para procesar datos de terceros que no formen parte de la propiedad configurada.

Cómo se utilizan los datos

Los datos se usan únicamente para generar y enviar un informe de diagnóstico al propietario del Monitor. El script no vende Google user data, no la usa para publicidad, no la transfiere a terceros para sus propios fines y no la publica en el sitio web. No se ha incorporado una base de datos externa o un servicio de analítica de terceros en el código del Monitor.

Procesamiento y almacenamiento

El script se ejecuta en Google Apps Script bajo la cuenta del propietario y utiliza servicios de Google para consultar Search Console, ejecutar solicitudes HTTP y enviar el correo. El contenido del informe también se escribe en el registro de ejecución de Apps Script para depuración. Google puede procesar los datos conforme a los términos y políticas aplicables a sus servicios. Los informes enviados permanecen en el buzón del destinatario según sus ajustes de correo.

El Monitor no guarda deliberadamente las respuestas de la API en una base de datos separada, pero los registros técnicos y los correos pueden conservar información del informe. El propietario puede eliminar mensajes y consultar o borrar los registros disponibles en su entorno de Apps Script sujeto a las funciones y políticas de Google.

Compartición

Los datos se envían a las API de Google y al servicio de correo de Google como parte de la función del Monitor. El reporte se entrega exclusivamente a la dirección configurada por el propietario. No hay integraciones de publicidad ni de venta de datos.

Seguridad y permisos

El Monitor solicita permisos para leer Search Console, realizar solicitudes HTTP, enviar informes por correo, administrar su activador semanal y conocer el correo de la cuenta. No necesita contraseñas copiadas en el código ni claves API incrustadas. El propietario puede revocar el acceso desde la configuración de su cuenta de Google y detener el activador desde Apps Script.

Cambios y contacto

Esta política se actualizará si cambia de forma sustancial el tratamiento de los datos. El Monitor está destinado al uso personal de su propietario; para consultas, utiliza el correo de soporte que aparece en la pantalla de consentimiento OAuth de Google Cloud.

Esta política describe la implementación prevista del script y no constituye asesoría legal. El propietario debe mantenerla fiel al código, a la configuración y a las prácticas reales.
