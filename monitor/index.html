Search Console Monitor

Un script personal de Google Apps Script que prepara informes periódicos sobre la disponibilidad de las páginas públicas de Cuota Clara, el estado conocido de indexación, el sitemap y las métricas de búsqueda de Google Search Console.

Solo lectura de Search Console · Informes al propietario

Qué hace el monitor

El monitor consulta la API de Google Search Console para revisar cuatro páginas de Cuota Clara, lee el registro del sitemap, comprueba que las páginas públicas respondan y obtiene métricas agregadas de clics, impresiones, CTR, posición y consultas. Después envía el informe a la dirección de correo configurada por el propietario.

El monitor no solicita indexación, no modifica páginas ni sitemaps, no publica los datos, no conecta cuentas de otros usuarios y no está diseñado para ofrecer un servicio a terceros. La inspección API refleja el estado que Google conoce; no sustituye la prueba de URL publicada en Search Console.

Este proyecto es una utilidad personal experimental, sin cobro ni garantía de resultados de búsqueda.
